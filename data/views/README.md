# LLM-generated views (Sections 4 and 5.4)

All outputs here were generated by Claude Haiku 4.5.

| File | Contents |
|---|---|
| `gloss_en.json` | Final write-time English glosses, keyed by unit id: 4,294 non-English memories (1,919 fact statements and 2,375 IndicTalk distractor turns). Memories that already look English are skipped by a language-ID check. Used by the Gloss and Gloss+QT views. |
| `qtrans.json` | English translations of the 960 non-English questions, used by the QT view. |
| `GLOSS_PROMPT.md` | The prompts used for glossing and question translation. |
| `opaque_ids.json` | The opaque ids under which texts were shown to the model, so that it could not tell target facts from distractors. |
| `gloss_in/`, `gloss_out/`, `gloss_done_part1.json`, `qtrans_in.jsonl` | Raw batch inputs and outputs of the first glossing pass. |
| `g2_in/`, `g2_out/` | Second pass. It regenerated the outputs that the automatic checks (`scripts/check_gloss.py`, `scripts/check_g2.py`) rejected as placeholders rather than translations. |

`gloss_en.json` and `qtrans.json` are what the experiments read. The batch folders are kept only so that the generation can be audited.
